Factory Inventory Management System

A full-stack demo application: a Vue 3 single-page app talks over HTTP to a Python FastAPI service, which serves data loaded into memory from static JSON files. No database — restart the server and it reloads from disk.

Request / Data Flow

1
User adjusts a filter
Time Period, Warehouse, Category, or Order Status changes in FilterBar.vue, updating shared refs in the useFilters() composable (singleton state).
2
View requests data
A page like Dashboard.vue calls getCurrentFilters() and passes the result into an api.js method, e.g. api.getInventory(filters).
3
Axios sends an HTTP GET
api.js builds a URLSearchParams and calls http://localhost:8001/api/..., omitting any filter set to "all".
4
FastAPI filters in memory
The route handler in main.py runs apply_filters() (warehouse / category / status) and filter_by_month() (direct month or quarter) against the in-memory Python lists — never mutating the originals.
5
Pydantic validates the response
Results are coerced into typed models (InventoryItem, Order, etc.) via response_model, then serialized to JSON.
6
Vue updates the UI
The response lands in a ref (e.g. allOrders); computed properties derive filtered/aggregated views, and the template re-renders reactively.

Demo Constraints

This is a workshop demo, not production infrastructure.
  • No database — data lives in Python process memory and resets on restart.
  • No authentication/authorization on the API.
  • CORS is wide open (allow_origins=["*"]) for local development.
  • Suitable for local development only.
