Factory Inventory Management

A demo full-stack inventory application: a Vue 3 SPA served by Vite talks to a FastAPI backend that filters in-memory JSON fixtures. No database, no auth — just a clean three-layer illustration of a filter-driven dashboard.

Data Flow

Every screen follows the same pattern: filter state drives a query string, the API filters an in-memory list, and Vue re-renders from reactive refs and computed properties.

1

User adjusts filters

The FilterBar component mutates refs exposed by useFilters — one of Time Period, Warehouse, Category, or Order Status.

2

View calls the API client

A view (e.g. Inventory.vue) reads the current filters and calls a method on api.js, which builds query params and fires an axios.get.

3

FastAPI applies filters in-memory

The endpoint calls apply_filters (warehouse, category, status) and filter_by_month (direct month or quarter via QUARTER_MAP) over the JSON list.

4

Pydantic validates & serialises

The response is typed against a BaseModel (InventoryItem, Order, …) so drift between the fixtures and the models surfaces as a 500 rather than a silent bug.

5

Vue re-renders from computed state

The view stores raw results in a ref (e.g. allOrders). Anything derived — totals, groupings, chart data — lives in a computed so it caches until the ref changes.
